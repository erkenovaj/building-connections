## Вопросы к созвону

1. **Железо у Сергея:** сколько GPU, какие (80GB?), есть ли интернет с кластера
   (HF download, comet). От этого зависит 8B-конфиг и нужен ли offline-режим.
2. **Comet:** чей workspace/project, куда класть API key.
3. **Бюджет времени:** сколько суток кластера реально есть → порядок E2/E3/E4.
4. **Приоритет ментора:** DFT-сравнение (E4) раньше или позже скейла (E3)?
5. **Гейты:** согласны с win@1 ≥ 0.05 (старт GRPO) и ≥ 0.6 (переход по curriculum)?

## Решения, уже принятые (чтобы не перерешивать)

- Терминальная награда `R = 1·[won] − 0.25·mistakes − 0.02·tool_calls`, без shaping
  (bandit-эксперименты с частичным кредитом давали локальные оптимумы).
- Curriculum 2→3→4 категории, отбор досок по эмпирическому win-rate.
- Гейт перед каждой GRPO-ступенью: win@k probe (не стартуем вслепую).
- Single-GPU baseline (1×80GB допущение), FSDP не делаем до ясности с железом.
- При провале гейта: один авто-ретрай через STaR, затем чистый стоп рана.
- Seeds: train 0+, STaR sample 150+, probe 1,000,000+, held-out eval 2,000,000+.
